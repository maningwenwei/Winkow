# Winkow · 摸鱼小窗

> 一扇随叫随到的小窗：看网页、刷视频、接手机投屏，鼠标移开就悄悄藏好，按一下老板键又回到眼前。

![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)
![Platform](https://img.shields.io/badge/platform-Windows-blue.svg)
![Electron](https://img.shields.io/badge/Electron-33.4.11-blue.svg)
![Version](https://img.shields.io/badge/version-1.0.62-green.svg)

Winkow（早期内部代号「摸鱼小窗」）是一个基于 Electron 的 Windows 桌面悬浮小窗工具。它把「临时看一眼」的内容收进一块可以瞬间隐藏的透明浮窗里：默认静音、不进任务栏、可从截图与屏幕共享中剔除，适合放在屏幕角落而不打扰手头的工作。

## 功能特性

### 一块随叫随到的小窗

- **无边框透明浮窗**：置顶显示，可拖到屏幕任意角落，贴边自动吸附；支持 8 个方向拖拽改变大小。
- **纯净模式**：去掉卡通边框与标题栏，只留内容本身，适合投屏或极简场景。
- **明暗主题**：浅色 / 深色 / 跟随 Windows 应用模式，首帧前就定好主题，避免闪屏。
- **动效可调**：收起与弹出的时长、缓动、透明度均可调，也支持「减少动效」直接切换。

### 秒藏秒现的「隐身」能力

- **老板键**（默认 `Alt+Q`）：按一次收起，再按一次唤回，可自定义。
- **鼠标移出自动隐藏**：光标离开窗口一小会儿后自动收起——但**刚启动时不生效**，只有第一次把鼠标真的移进浮窗再移出才「武装」，不会出现「一打开就没了」。
- **失焦自动隐藏**：切到别的窗口后收起（默认关闭，可开启）。
- **边缘窥视恢复**：光标贴住屏幕边缘停留片刻即可唤出，热区位置、宽度、时长可调。
- **独立的隐藏状态机**：用「隐藏原因集合」替代布尔值——老板键 / 托盘 / 手动是粘性原因（必须显式解除），鼠标移出 / 失焦是自动原因（条件反转即恢复）。多个来源互不覆盖，隐私语义清晰。
- **设置快捷键**（默认 `Alt+Shift+S`）：即使浮窗已隐藏，也能随时打开设置。

### 三种内容形态

- **待机**：启动时的默认界面，一只探头的小狐狸。
- **网页**：内置多标签浏览，前进 / 后退 / 刷新、地址栏、收藏夹、历史记录（默认最多留 7 天）、`Ctrl + 滚轮` 缩放、新标签页拦截。网址默认不落盘。
- **iOS 屏幕镜像（AirPlay）**：内置接收引擎，iPhone 控制中心 → 屏幕镜像 → 选这台电脑 → 输入 PIN 即可投屏。支持竖屏 / 横屏分辨率、帧率、投放声音、断线自动重连、按手机比例自适应窗口。

### 隐私优先的设计

- **默认静音**：开机即生效，网页与投屏声音统一走系统音量合成器，不影响其它程序音量。
- **隐藏时暂停播放**（仅网页）：收起时暂停网页里正在播的视频 / 音频，唤回时只续播「被我们停下的」，不打扰本来就没在播的页面。
- **防截屏 / 防录屏**：浮窗内容从截图与屏幕共享中剔除。
- **不进任务栏与 Alt-Tab**：切换窗口时看不到它。
- **独立 session 分区**：浏览内容与主界面隔离；不采集任何遥测，配置只写在 `userData` 目录。
- **一键清空痕迹**：缓存、Cookie、存储与历史一次清干净。

## 快速开始

1. 到 [Releases](../../releases) 下载适合你的安装包：
   - **`Winkow-x.y.z-Setup.exe`** — 安装版，可自选安装目录、创建桌面与开始菜单快捷方式。
   - **`Winkow-x.y.z-portable.exe`** — 便携版，免安装，双击即用。
2. 启动后浮窗停在**待机**界面，默认静音。
3. 记住两个动作：**鼠标移出浮窗自动收起**，**按 `Alt+Q` 随时收起 / 唤回**。
4. 顶部胶囊里的按钮依次是：网页 / 投屏切换、静音、放大缩小、更多、最小化。

> 首次使用时如果系统防火墙弹窗，请选择「允许访问」——AirPlay 接收需要本机端口通信。

## 使用方法

### 隐藏与恢复

| 操作 | 方式 |
| :--- | :--- |
| 收起 / 唤回 | 按老板键（默认 `Alt+Q`） |
| 自动收起 | 鼠标移出浮窗并停留一小会儿（首次启动后需先移入一次才生效） |
| 失焦收起 | 切到别的窗口（需在「设置 → 隐藏」里开启） |
| 边缘唤回 | 光标贴住屏幕边缘（默认右侧）停留片刻 |
| 托盘操作 | 右键托盘图标可切换内容、静音、清空痕迹、退出 |
| 只开设置 | 按 `Alt+Shift+S`，即使浮窗已隐藏也能打开 |

### 看网页

点击顶部「网页」按钮切到网页模式，在地址栏输入网址即可。地址栏旁提供搜索、收藏（星标）、前进后退与新建标签页。收藏与历史在星标旁的下拉面板里查看。

- 网页模式下窗口会自动掰成横屏比例，回到待机时还原。
- 在网页里按 `Ctrl + 滚轮` 可缩放内容；设置里也能统一调整。
- 「记住网址」默认关闭，关掉时历史不落盘但收藏仍保留。

### 接手机投屏

1. 点浮窗右上角的「开始接收」，画面中央会显示一个 4 位 PIN。
2. iPhone 打开 **控制中心 → 屏幕镜像**，选择设备名（默认 `Winkow`）。
3. 输入 PIN，即可看到手机画面出现在浮窗里。
4. 手机和电脑需连**同一个 Wi-Fi**；第一次启动若防火墙提示，选「允许访问」。

> 投屏期间会自动抑制「鼠标移出自动隐藏」，避免你看手机时小窗突然消失；老板键仍然可以手动隐藏。

更多高级选项（分辨率、帧率、固定 PIN、免 PIN 兼容、详细日志等）在「设置 → 投屏 → 高级选项」里。

### 设置

按 `Alt+Shift+S` 或托盘菜单打开设置，共五个分区：

- **常规**：主题、动画、透明度、置顶、边缘吸附、纯净模式、缩放、静音、隐藏时暂停播放。
- **隐藏**：老板键、设置快捷键、自动隐藏规则、边缘窥视、手感微调。
- **投屏**：AirPlay 开关与 PIN、分辨率、帧率、投放声音、外部视频源与中继。
- **隐私**：防截屏、任务栏、托盘、记住网址、开机自启、清空痕迹。
- **关于**：版本信息、使用说明与本版更新内容。

## 技术细节

### 技术栈

| 层面 | 选型 |
| :--- | :--- |
| 桌面框架 | Electron 33.4.11（Windows x64） |
| 打包 | electron-builder 26.18（NSIS 安装版 + portable 便携版） |
| 原生调用 | `koffi` 调用 Win32 API（窗口枚举、音频会话、真实鼠标位置） |
| 视频解码 | WebCodecs（H.264 裸流直出链路） |
| 投屏引擎 | 第三方 UxPlay 分支（GPLv3，独立分发，见[版权章节](#开源许可与版权保护)） |
| 脚本运行时 | Node.js ≥ 18 |

### 进程与模块架构

应用采用 Electron 标准的三层结构，业务逻辑全部下沉到独立模块，`src/main/index.js` 只负责「接线」：

```
src/
├── main/           主进程：窗口、隐藏状态机、热键、鼠标监听、音频策略、
│                   IPC、配置存储、AirPlay 引擎、投屏中继、诊断
├── preload/        contextBridge 安全桥：渲染层与 IPC 的唯一通道
├── renderer/       渲染层：浮窗 UI、设置 UI、WebCodecs 解码器
└── shared/         三方共用的 IPC 频道与常量
```

所有跨进程通信频道集中在 `src/shared/constants.js` 的 `CH` 表里，避免字符串散落；渲染层通过 `contextBridge` 暴露的受限 API 调用主进程，`contextIsolation: true`、`nodeIntegration: false`。

### 隐藏状态机

`src/main/hideController.js` 是核心。它维护一个「隐藏原因集合」：

- **粘性原因**（`hotkey` / `tray` / `manual`）：必须由用户显式解除；
- **自动原因**（`mouseLeave` / `blur`）：条件反转时自动解除并恢复显示。

只有当粘性原因清空、自动原因也都解除，窗口才恢复。另有「唤出保护期」（`suppressUntil`）防止刚显示就又被收起，`autoArmed` 标志确保启动那一下不会因为光标恰好在外面而立刻隐藏。

### 窗口与显隐动画

`src/main/windows.js` 里，浮窗是一扇 `frame: false` + `transparent: true` 的 `BrowserWindow`。**显隐动画完全在渲染层的合成层上做**（`scale` / `translateY` / `opacity`），窗口矩形全程恒定——这样避免了反复 `setBounds` 带来的抖动与闪烁。收起是「淡出 + 缩小 + 下沉」，恢复是带回弹的「探头」。

透明窗口上 `-webkit-app-region: drag` 在 Windows 上不可靠（`WM_NCHITTEST` 恒返回 `HTCLIENT`），因此窗口拖动改为**自绘方案**：渲染层把指针相对位移通过 IPC 发给主进程，主进程按起始 bounds 调 `setBounds`。8 向缩放同理。

### 音频策略

`src/main/audio.js` 通过常驻的音频宿主（C# / Win32 音频会话）把网页与投屏声音绑定到系统音量合成器，实现「开机即静音、只静音本程序、不影响其它程序」。首次收起时会预热宿主（预编译类型），避免第一次静音慢半拍。（1.0.59 起移除了「隐藏时系统静音」——它会连带压住整机输出，收益小于风险。）

### AirPlay 双画面链路

投屏引擎支持两条画面通道，默认走第一条：

1. **vnet 直通**：引擎以 `-vnet` 把解密后的 H.264 裸码流推到本地 TCP（`127.0.0.1`），主进程收下后直传浮窗，由 WebCodecs 解码渲染。没有视频窗口、没有桌面捕获，CPU 占用更低。会话首帧（带 SPS/PPS）会被缓存，浮窗崩溃重载后可补发，避免「画面再也回不来」。
2. **窗口捕获回退**：引擎自解码到独立视频窗口（d3d11videosink），浮窗用 `getDisplayMedia` 捕获。仅在 vnet 不可用时回退。

引擎视频窗口会被「收拢」到浮窗背后，跟随浮窗拖动 / 缩放；隐藏时连窗口一起藏好，防止画面泄漏。所有端口只绑定本机回环。

### 隐私实现要点

- `setContentProtection(true)` 让窗口内容从截图与屏幕共享中剔除；
- `skipTaskbar` 会置 `WS_EX_TOOLWINDOW`，任务栏与 Alt-Tab 都不出现；
- 浏览内容跑在 `persist:moyu-content` 独立分区，与主界面隔离；
- 设置窗口通过 `setAlwaysOnTop(true, 'screen-saver')` 保证层级在浮窗之上。

### 诊断与自测

项目内置大量探针与端到端脚本（`scripts/` 与 `tools/`），可无人工干预验证启动链路、网页视口、AirPlay 投屏画面、面板弹出等。例如 `MOYU_SMOKE=1 electron .` 可跑一次启动自检后自动退出。

## 从源码构建与开发

需要 Windows 10/11 x64、Node.js ≥ 18。

```bash
# 安装依赖
npm install

# 源码运行（推荐用附带的启动器，它会处理 ELECTRON_RUN_AS_NODE 等环境变量）
运行-开发版.cmd
# 或： npx electron .

# 打包（生成 Setup + portable 到 dist/）
npx electron-builder --win
```

常用调试开关：

- `MOYU_SMOKE=1`：跑一遍启动自检后自动退出，日志写到 `MOYU_SMOKE_LOG` 指定的文件。
- `MOYU_AIRPLAY_START=1`：触发 AirPlay 端到端自检。
